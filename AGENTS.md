# Instrucciones del proyecto

Antes de empezar una tarea, revisa la lista de skills de abajo. Lee la skill pertinente y guíate por ella; si hacen falta varias, consulta solo las relacionadas. Luego consulta `docs/project.md` cuando necesites contexto del proyecto.

Trabaja con cambios pequeños, claros y acordes con la arquitectura existente. Antes de editar, inspecciona el código relacionado y la documentación pertinente. No supongas que una solución funciona: verifica el comportamiento afectado y comunica qué comprobaste y qué no pudiste comprobar.

Consulta solo lo necesario:
- `docs/project.md`: contexto y decisiones propias de este proyecto.
- `.agents/skills/web-design/SKILL.md`: diseño o mejora visual de páginas.
- `.agents/skills/frontend/SKILL.md`: React, UI, Tailwind o componentes.
- `.agents/skills/react-native/SKILL.md`: aplicaciones móviles React Native o Expo.
- `.agents/skills/api-dotnet/SKILL.md`: API y servicios .NET.
- `.agents/skills/firebase/SKILL.md`: Firebase, Firestore, Authentication, Storage o Functions.
- `.agents/skills/data-security/SKILL.md`: MongoDB, permisos o datos sensibles.
- `.agents/skills/qlik-mashup/SKILL.md`: Qlik Sense y mashups.
- `.agents/skills/verify/SKILL.md`: cambios funcionales y pruebas.

Prefiere HTML semántico, accesibilidad, diseño adaptable y lógica reutilizable sin abstracciones innecesarias. Usa Flexbox o Grid según el diseño; margin y padding para espaciar son válidos. Valida entradas y permisos en el servidor. Añade pruebas útiles para comportamiento nuevo o corregido. No incorpores dependencias sin justificar su beneficio.
